I use Ghostty's Quick Terminal as a shortcut to one OpenCode session that is already running in my Obsidian vault as its working folder. Todoist is connected through MCP, and an `AGENTS.md` file in the vault tells OpenCode where tasks, notes, and journal entries belong.

When I want to capture something, I press <code>Cmd + `</code>. Quick Terminal appears over the app I am using, so I can speak with [dictation](./dictation)

Depending on what I say, OpenCode can add a task to Todoist, update an existing note, or create a journal entry. The setup is simple: the persistent session already has the right folder and instructions, and Quick Terminal is just the fast way back to it. I can capture the thought first and let the agent handle where it belongs.
