OpenChamber is my cockpit to use opencode.

It wraps OpenCode in an interface that brings browser and code review together. I can annotate a page, make a change, create notes, check the result, review the diff, stage fixes one at a time, and commit, all in one place. I used Codex desktop for this workflow before discovering OpenChamber, and have since switched, it lets me continue sessions from my opencode tui directly inside openchamber and vise versa.

For deeper coding work, Zed is still my primary editor: its navigation, completions, and diagnostics are essential. I keep using OpenCode's terminal interface for workflows that suit it better.

I love how thoughtfully OpenChamber brings tools together, but I don't want the workflow to depend on one app or coding agent. I'm working to bring the parts I rely on, including visual annotations, walkthrough, staging, and commits, into a more agent- and tool-agnostic setup, so I can switch agents without losing the workflow.
